# Orbits Simulation: Bash Example

This repository contains a bash script for running various orbital simulations using the Orbits simulation module. The script demonstrates how to use the command-line interface to simulate different celestial bodies in orbit.

## Prerequisites

Before running the script, ensure you have:

- Python 3.7 or higher
- The Orbits simulation module installed
- Bash shell environment
- Basic command-line knowledge

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/orbits-simulation.git
   cd orbits-simulation

2. Install the orbits package if not already installed
   '''bash
   pip install -e .
2. Make the script executable:
   '''bash
   chmod +x examples/bash_examples/run_orbits.sh

## Usage
Run the script from the repository root:
'''bash
./examples/bash_examples/run_orbits.sh
